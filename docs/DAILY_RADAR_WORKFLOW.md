# Daily Radar → Notion Workflow

```text
Daily task
→ check existing vocabulary
→ create Candidate
→ enrich fields and context
→ manually approve
→ Sync approved signals
→ mark successfully imported records as Imported
```

Daily work does not write Core Signals, does not automatically approve a Candidate, and does not automatically create a Quiz. Keep the original source and discovery context. Do not create a second record for an exact duplicate; a different category or genuinely different usage boundary may justify a separate Signal. Mark internet expressions with an appropriate Change Risk such as Evolving or Trend.
