# English Radar v1.6.0 — Community Discourse

V1.6.0 introduces optional Content Pack 04 for Community Discourse.

## Included

- 10 Community Discourse Signals
- 20 dedicated Quizzes
- `culturalContextEn` / `culturalContextZh` optional semantic fields
- Generic Learn rendering for original meaning, cultural context, related expressions, and confusions
- Dictionary search coverage for rich semantic fields
- Community Discourse integration with Daily Mix and Category Focus
- Pack 04 preview, install, remove, reload, and reinstall lifecycle

## Compatibility

- No LocalStorage migration
- No new LocalStorage key
- No Worker changes
- No Notion API changes
- No framework or dependency changes
- Pack 01, Pack 02, Pack 03, and Interface Vocabulary remain independently validated
- v1.5.0 Tag and Release remain unchanged
