# English Radar V1.3.0

Date: 2026-08-07

V1.3.0 adds the optional Content Pack 01 — Product Interface & Builder Workflow.

- 24 audited Signals: 15 UI Vocabulary and 9 Builder Vocabulary.
- 48 dedicated quizzes: exactly 2 per Signal.
- Optional Me → Content Library installation with preview, idempotent reinstall, and removal that preserves Progress and Quiz History.
- Static quiz registration is gated by active Signals, so uninstalled Pack 01 questions are not answerable.
- User-facing page metadata, asset cache-busting, and release labels are aligned to V1.3.0.

This release does not change LocalStorage keys, `dataVersion`, `contentVersion`, Worker credentials, Notion data, or existing Core/UI Core content.
