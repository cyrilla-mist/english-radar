# English Radar v1.2.0

English Radar v1.2.0 makes the product interface part of the learning material while keeping the existing local-first learning system intact.

## Highlights

- Interface Learning Mode for explicitly marked UI Vocabulary targets.
- A bundled UI Vocabulary Core Pack with 10 interface Signals.
- Interface-context quizzes: 20 stable questions covering the UI vocabulary pack.
- Interface-aware Learn, Dictionary, Today, Quiz and Review flows with graceful fallback for older Signals.
- Daily Mix, Unseen Discovery, Category Focus and the expanded Review schedule remain available.
- Dictionary pagination, Installed Packs management and the shared Today snapshot remain unchanged in scope.
- Full-library mobile performance work keeps normal initialization responsive with 796 Active Signals.

## Content counts

- 60 Core Signals.
- 120 runtime Core Quizzes: 30 hand-authored questions plus 90 deterministic generated questions from the existing Core data.
- 20 UI Vocabulary Quizzes.
- 140 static quizzes in the combined Core and UI registry.
- 140 migrated Notion archive Signals remain an optional bundled archive and are not part of Core data.

## Boundaries

The release remains native HTML, CSS and JavaScript. Interface Learning Mode uses explicit data markers and session-only state; it does not scan arbitrary page text or write a new persistent data schema. Existing LocalStorage records, Content Pack schemas, Notion Sync and the Cloudflare Worker are unchanged.

## Validation

The release candidate is checked by the existing data, project, Learning Engine, Quiz Engine, performance, bilingual UX and Worker tests, plus V1.2 interface schema, bundled pack, learning loop, category collapse, interface mode, UI quiz data and release-readiness tests.
