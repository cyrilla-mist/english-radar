# English Radar v1.5.0 — Interface Structure & Overlays

## Scope

V1.5.0 adds optional Content Pack 03 for Interface Structure & Overlays.

- 10 audited UI Vocabulary Signals.
- 20 dedicated quizzes.
- 10 Interface Signals.
- Pack 03 participates in the normal Quiz flow and Interface Check.
- Pack 03 does not automatically expand the clickable Interface Learning page-target source.
- Pack 01, Pack 02 and Pack 03 install and remove independently.
- Progress and Quiz History are preserved when a pack is removed.

## Compatibility boundaries

- No LocalStorage key or schema migration.
- No Worker deployment.
- No Notion API change.
- No rewrite of Core, UI Core, Pack 01 or Pack 02 content.
- Optional packs are not active until the user installs them locally.
