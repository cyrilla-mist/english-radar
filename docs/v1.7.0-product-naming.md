# English Radar v1.7.0 — Product Naming

V1.7.0 adds optional Content Pack 05, Product Naming, as the next layer of the Global Internet English Knowledge Base. It teaches the naming patterns users meet in navigation, search, saving, collaboration and information architecture.

The pack contains ten Signals and twenty quizzes:

- Explore, Discover, Draft, Collection, Library
- Queue, Hub, Spaces, History, Saved

Each Signal keeps the existing normalized schema and adds no new persistent fields. Product Meaning, Original Meaning, Why Products Use It, Common Interfaces, Real Interface Examples, related terms and confusion guidance are rendered through the existing rich Learn presentation. Interface Learning Mode remains specialized and unchanged.

Pack 05 is optional, local-first and installed through the existing Content Library lifecycle. Its source audit records are kept beside the pack manifest and its quiz registry uses only the existing meaning, context and boundary question types.

The bundled pack registry is now self-registering. Adding a future bundled pack requires its data and quiz files to register themselves; the consumer modules no longer maintain a linear Pack 01–05 list.
