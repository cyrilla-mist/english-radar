# English Radar v1.8.0 Release Notes

## Archive Mode

- Added a formal Archive catalog with My Archive and Catalog scopes.
- Added active/available visibility, bundled pack attribution and duplicate-term grouping.
- Added Archive detail actions for Learn and Content Library.
- Added responsive Archive navigation, skip links and cache-busted v1.8 assets.
- Kept scope state non-persistent and preserved existing Content Library install/remove state.

## Boundaries

- No new quiz type, LocalStorage key, schema migration, backend, Worker deployment or Notion API mutation.
- Uninstalled bundled Signals remain unavailable to learning and quizzes until installed through Content Library.
