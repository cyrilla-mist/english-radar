# English Radar v1.4.0 — AI Foundations

English Radar v1.4.0 adds the optional AI Foundations Content Pack 02.

- 10 audited AI Builder Signals.
- 20 dedicated quizzes, exactly 2 per Signal.
- Optional bundled-pack installation with preview, idempotent reinstall, and removal.
- Pack 02 joins the normal learning and quiz flows but is excluded from Interface Check.
- Content Pack 01 and Content Pack 02 have independent installation and removal state.
- Removing either pack preserves learning Progress and Quiz History.
- No LocalStorage key or schema migration is introduced.
- No Worker deployment or Notion API change is included.
- Existing Core, UI Core, and Content Pack 01 content is not rewritten.

The release keeps the existing local-first English Radar architecture and adds no new dependency or backend subsystem.
