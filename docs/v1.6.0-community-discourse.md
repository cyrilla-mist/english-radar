# English Radar v1.6.0 — Community Discourse

## Purpose

Community Discourse extends English Radar from vocabulary recognition toward a local-first knowledge base for real internet English. It records where a signal appears, how it sounds, what its boundaries are, and why an internet community uses it.

## Signal model

The pack uses the existing Signal model and adds only two optional fields:

- `culturalContextEn`
- `culturalContextZh`

`meaningEn` / `meaningZh` remain the Internet Meaning. Existing `originalMeaningEn` / `originalMeaningZh`, `platforms`, `tone`, `useWhen`, `avoidWhen`, `relatedTerms`, and `confusedWith` are generalized as optional semantic fields. Older Core, Imported, and Interface Signals remain valid when these fields are absent.

- Category: `Community Discourse`
- Installation: preview, install, hard reload, remove, hard reload, reinstall

The first pack covers OP, thread, lurk / lurker, ratio, dogpile, doomscroll, touch grass, hot take, low-key / high-key, and rent-free.

Each Signal has two questions: one Meaning / Context recognition question and one Usage Boundary / Tone / Community context question. No new Quiz type is introduced.

## Content boundary

The pack is educational, not a recommendation to use every expression actively. Signals such as ratio, dogpile, touch grass, and rent-free require attention to audience, hostility, vulnerability, and platform context.

## Sources

Each Signal includes a source name, source URL, source type, and audit date. Sources are platform help documentation or established dictionary and slang references. The pack distinguishes a definition from an inference about tone or social risk.
