# English Radar v1.8.0 — Archive Mode

v1.8.0 formalizes Archive Mode as a local-first catalog for the Global Internet English Knowledge Base.

## Visibility

- **My Archive** shows active Core, installed bundled, imported/custom, Personal and other active registry Signals.
- **Catalog** adds all bundled Pack 01–05 Signals without activating them.
- Uninstalled bundled entries are marked `Available in Pack XX / Not installed` and do not enter Learn, Review or Quiz.
- Scope is session-only UI state. No new LocalStorage key or migration is introduced.

## Routes and navigation

Archive list: `archive.html`; detail: `archive-signal.html?id=<signal-id>`.
Active detail records link to `learn.html?mode=lookup&signal=<id>`. Available records link to `me.html#content-library`.
Desktop navigation has six items. Mobile keeps five items and exposes Inbox through Today.

## Compatibility

The implementation reuses the existing Signal registry, bundled pack registry, Content Library lifecycle and Learn lookup route. No backend, Worker, framework or Notion write is involved.
